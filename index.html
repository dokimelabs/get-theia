Install theia. The installer asks you to sign in with Google, GitHub or Microsoft; access is by invitation.

curl -fsSL https://dokimelabs.github.io/get-theia/install.sh | sh

Run it in a terminal. It installs to ~/.local/bin and needs no admin rights.

Optional add-ons

After theia is installed, in the same terminal. Each downloads with the sign-in the installer saved.

Claude Code skills

/analyze and /chronicle, installed into Claude Code's skills folder.

theia claude install

SPI masking

Transparent masking of sensitive data for upstream model requests.

theia spi install && theia spi enable
