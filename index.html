Install

Linux / macOS

curl -fsSL https://dokimelabs.github.io/get-theia/install.sh | sh

The installer detects your OS and architecture, asks for the GitHub PAT your organization issued for release access (or reads $THEIA_PAT), verifies checksums, verifies the binary runs, and installs theia to ~/.local/bin. Re-running it replaces an existing install wholesale — it is also the recovery lever.

To pin an exact release instead of the latest:

curl -fsSL https://dokimelabs.github.io/get-theia/install.sh | THEIA_VERSION=0.2.201 sh

Windows

Windows runtime support has landed and the release carries an installer kit. theia-releases is private, so downloading it needs the fine-grained GitHub token your organization was issued — the same token the Linux and macOS installer asks for. Run these in PowerShell; the installer itself needs no administrator rights.

1. Put your access token in the session, then download the Windows kit for the latest release:

$env:THEIA_PAT = "github_pat_…"
$hj = @{ Authorization = "Bearer $env:THEIA_PAT"; Accept = "application/vnd.github+json" }
$hb = @{ Authorization = "Bearer $env:THEIA_PAT"; Accept = "application/octet-stream" }
$api = "https://api.github.com/repos/dokimelabs/theia-releases"
$rel = Invoke-RestMethod "$api/releases/latest" -Headers $hj
$arch = if ($env:PROCESSOR_ARCHITECTURE -eq "ARM64") { "aarch64" } else { "x86_64" }
# URL LINE
$asset = $rel.assets | Where-Object { $_.name -like "*windows-$arch*" } | Select-Object -First 1
if (-not $asset) { throw "release $($rel.tag_name) carries no Windows kit" }
Invoke-WebRequest $asset.url -Headers $hb -OutFile "$env:TEMP\$($asset.name)"

2. Unpack it and step into the folder holding install.ps1:

$kit = "$env:TEMP\theia-kit"
New-Item -ItemType Directory -Force -Path $kit | Out-Null
tar -xf "$env:TEMP\$($asset.name)" -C $kit
Set-Location (Get-ChildItem $kit -Recurse -Filter install.ps1 | Select-Object -First 1).Directory

3. Optional — drop your token into PAT.txt beside the installer so it can configure updates for you. Skip this and set it later with theia setup --pat <token>:

$env:THEIA_PAT | Set-Content -Encoding ascii PAT.txt

4. Run the installer:

powershell -ExecutionPolicy Bypass -File .\install.ps1

It installs into %LOCALAPPDATA%\dokimelabs\theia\app for your user only, adds that folder to your PATH, and finishes by printing theia doctor. Re-running it is safe — it reinstalls over the top and leaves your config alone. Then open a new terminal, where theia is on the path.

Releases and access

Release artifacts live in dokimelabs/theia-releases, a private repository — distribution is the access gate. Downloads (and the installer) authenticate with a fine-grained GitHub token that dokimelabs issues per customer; ask your dokimelabs contact for a release token if you don't have one. The token can download releases and nothing else.
